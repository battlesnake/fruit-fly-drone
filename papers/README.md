# Paper bundle and reading list

Downloaded from the official author-hosted bioRxiv record:

- `malecns-preprint-v2.pdf`: MaleCNS manuscript v2;
- `malecns-preprint-v2-supplement-1.pdf`: supplementary figures;
- `malecns-preprint-v2-supplement-2.pdf`: supplementary tables/notes.

Downloaded from the official open-access Nature records:

- `lappalainen-2024-connectome-constrained-visual-networks.pdf`;
- `shiu-2024-drosophila-computational-brain.pdf`.

The peer-reviewed version is Berg et al., *Cell* (2026), DOI
[10.1016/j.cell.2026.08.015](https://doi.org/10.1016/j.cell.2026.08.015). The preprint and
supplements are available at
[bioRxiv 2025.10.09.680999v2](https://www.biorxiv.org/content/10.1101/2025.10.09.680999v2).

Related primary work used in the design plan (the two articles are mirrored here as their
official open-access PDFs):

- Lappalainen et al., [connectome-constrained visual networks](https://www.nature.com/articles/s41586-024-07939-3)
  and [official Flyvis code](https://github.com/TuragaLab/flyvis).
- Shiu et al., [whole-brain sensorimotor modelling](https://www.nature.com/articles/s41586-024-07763-9)
  and [official code](https://github.com/philshiu/Drosophila_brain_model).

PDFs are tracked through Git LFS to avoid placing large binary blobs in ordinary Git
history.
