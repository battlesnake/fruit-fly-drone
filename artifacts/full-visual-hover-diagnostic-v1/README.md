# Full-connectome visual hover diagnostic v1

This artifact records a **passed causal marker-response diagnostic and a failed
closed-loop hover attempt**. It is not a promoted flight checkpoint.

The 320 by 200, 125-degree RGB camera drives 2,197 mapped photoreceptors in a recurrent
graph containing every 165,122 traced MaleCNS v1.0 neuron and 2,749,407 edges above the
declared ten-synapse threshold. Estimated roll/pitch is present; acceleration, mass,
hover thrust and external history are absent from the actor.

The paired learner trained from base vehicle/reference heights in 0.60-0.85 m and
1.15-1.40 m, then passed from a held-out 0.90-1.10 m base interval. The two conditions
shared pose, texture and neural state; only the physical marker moved. The trained
response achieved 0.134 normalized RMSE, 100% correct sign and slope 0.964 over 64 pairs.
Because the marker then moves by plus or minus 0.20 m, the final marker-height ranges
overlap; this diagnostic proves marker causality, not fully disjoint absolute-height
generalization.

A paired-mean contrast clamp leaves only 33.4% of the marker-to-throttle contrast when
applied to non-motor VNC or `vnc_intrinsic` neurons, but 105.1% when applied only to
`vnc_sensory` neurons. This is evidence that VNC intrinsic recurrence is causally used in
the fixed response assay. FeCO/stick feedback is not yet connected, and full hover still
fails because absolute collective and vertical damping drift.

[`report.json`](report.json) is a small committed record of results and hashes. The
generated 16 MB graph and 78 MB checkpoints remain ignored; they can be regenerated by
the scripts described in [`docs/VISUAL_HOVER.md`](../../docs/VISUAL_HOVER.md). No new
binary belongs in Git or Git LFS. The derived graph follows the upstream MaleCNS CC BY
4.0 terms recorded in [`data/README.md`](../../data/README.md).
